# Установка ReChan VR Standalone на Quest 3

Игра работает нативно на шлеме. Компьютер и USB нужны для первоначальной установки
и переноса вашей копии игры; во время игры они не требуются.

## Что понадобится

- Quest 3, контроллеры Touch, USB-кабель с передачей данных.
- Режим разработчика и подтверждённая в шлеме отладка по USB.
- Компьютер с Android Platform Tools (`adb`) и оболочкой Bash.
  На Windows можно использовать настроенный Git Bash или WSL.
- **APK из [GitHub Releases](https://github.com/Yurgil/ReChan-VR-Standalone/releases)**
  или [собранный из исходников](BUILDING.md). Готовая сборка использует стабильную
  подпись для обновлений и поддерживает импорт данных через `run-as`.
- **Собственная законно полученная копия Jackie Chan Stuntmaster NTSC-U, SLUS-00684**.

Образ и извлечённые игровые данные не входят в проект. Архив ZIP/7z нужно заранее
распаковать: скрипту передаётся настоящий BIN/ISO, а не архив или CUE. PAL и другие
версии диска не являются поддерживаемой целью. Работа изменённых образов в общем
случае не гарантируется.

## Установка

Скачайте исходники репозитория или подготовленный пакет исходников. Откройте Bash
в его корневой папке. Подключите шлем и проверьте:

```bash
adb devices
```

Шлем должен иметь статус `device`. При `unauthorized` наденьте шлем и подтвердите
отладку. Если подключены несколько устройств, задайте `ANDROID_SERIAL` для своего
Quest локально.

Укажите пути к ADB, APK и своему образу:

```bash
ADB=/полный/путь/к/adb APK=/полный/путь/к/app-debug.apk \
  scripts/run_quest.sh game '/полный/путь/к/своему/game.bin'
```

Если используются локальные инструменты проекта и стандартный результат сборки:

```bash
scripts/run_quest.sh game '/полный/путь/к/своему/game.bin'
```

Скрипт установит APK, скопирует образ в закрытую папку приложения, проверит размер
копии и запустит игру. В шлеме подтвердите извлечение ресурсов, если появится запрос,
и дождитесь завершения. Если Quest просит контроллеры — разбудите оба Touch.

Текущий импорт работает через ADB и `run-as`, поэтому нужен именно **debug APK**.
Встроенный Android-выбор папки пока не проверен на Quest. Одна установка обычного
release APK не заменяет импорт вашей копии игры.

## Последующие запуски и обновления

Запускайте **ReChan Quest** из библиотеки шлема / «Неизвестные источники».
Компьютер, USB, SteamVR и трансляция с ПК больше не нужны.

Для обновления без повторной передачи образа:

```bash
ADB=/полный/путь/к/adb APK=/полный/путь/к/новому/app-debug.apk \
  scripts/run_quest.sh game
```

APK должен быть подписан тем же ключом. Установка поверх сохраняет данные;
удаление приложения или очистка хранилища удаляют его локальные сохранения и
импортированные ресурсы. Простая передача другого образа не заменяет уже
извлечённый набор данных автоматически.

## MR и перенос Джеки

В Options включите Mixed Reality. Одновременное нажатие обоих стиков переключает
редактирование окна: контур становится голубым. Курком/grip захватите полосу рамки
для переноса, угол — для размера. Два контроллера позволяют масштабировать окно.
Для рук отложите Touch, подождите 1,25 секунды и сделайте новый щипок на рамке.
В этом режиме тестового куба больше нет. Выбор размера в Options удалён:
масштаб меняется непосредственно руками/контроллерами. Трекеры рук активируются
только в синем режиме после откладывания обоих Touch; при поднятии контроллеров
или выходе из режима они отключаются.

Для Джеки отдельно включите **Room interaction → Interact with Jackie** и войдите
в MR-редактирование. Подтвердите доступ к помещению: готовый скан Quest используется
повторно, а при отсутствии откроется системная настройка. Обычному MR-окну скан не нужен.

В игровом уровне приблизьте окно, отложите Touch и захватите щипком область тела
Джеки у поверхности проёма. Его можно вытащить и поставить на отсканированную
поверхность. Снаружи его рост в исходной стойке — 10 см. Для возврата захватите его,
внесите за поверхность окна и отпустите. Пока Джеки снаружи, исходный уровень
продолжает работать, а его скрытый игровой экземпляр не двигается и не получает урон.

Чтобы управлять Джеки на столе, оставьте режим взаимодействия включённым, возьмите
Touch и один раз отпустите кнопки/верните стики в центр. Левый стик — движение
относительно направления головы; правый курок — прыжок с лёгкого нажатия;
A — удар рукой, B — ногой, правый grip — перекат. Правый стик вверх/вниз меняет
размер от 5 до 156,6 см по исходной стойке модели, по умолчанию — 10 см. Скан задаёт опору, стены,
мебель и границы одного помещения. При выходе из режима Джеки возвращается в игру.
Комнатное управление — новая экспериментальная функция0.10.0; враги исходного
уровня в комнату не переносятся.

Раскладка кнопок — в [README](../../README.md). В публичные сообщения об ошибках
не прикладывайте образ, извлечённые ресурсы, сохранения или снимки вашей комнаты.


Надпись SCENE на хлопушке показывает этап или MAIN MENU. TAKE начинается с01,
увеличивается после смерти/перезапуска и сбрасывается при выходе в главное меню
или game over. Обычная пауза и Options счётчик сохраняют.


До извлечения игровой мир останавливается при редактировании окна или полной
потере обоих Touch дольше 0,5 секунды. Краткая смена профиля ввода, недоступность
отдельного стика или одного Touch больше не блокируют весь игровой мир.
